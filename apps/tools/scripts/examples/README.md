# Sample photos

The before & after sample on the home page (`render-examples.mjs`) is drawn from
these two photos. Both are from Pexels, under the [Pexels license](https://www.pexels.com/license/):
free to use, including commercially, with no attribution required.

| File         | Source                                                                                                |
| ------------ | ----------------------------------------------------------------------------------------------------- |
| `before.jpg` | [A person doing a manicure](https://www.pexels.com/photo/a-person-doing-a-manicure-14267564/)            |
| `after.jpg`  | [Elegant manicured hands with gold jewelry](https://www.pexels.com/photo/elegant-manicured-hands-with-gold-jewelry-34373403/) |

To show a real salon's work instead, replace both files (portrait photos work
best) and run `pnpm --filter @reserva/tools examples` again.
